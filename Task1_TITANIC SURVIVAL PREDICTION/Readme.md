# Titanic Survival Prediction using Machine Learning

## Project Overview

This project predicts whether a passenger survived the Titanic disaster using machine learning techniques.

The dataset contains passenger information such as:

* Age
* Gender
* Passenger Class
* Fare
* Family Details

The goal is to analyze the dataset and build classification models to predict survival accurately.
